# Intelligent Home Automation

## 📌 Overview
This project is an IoT-based intelligent home automation system designed to control and monitor home appliances efficiently.

## 🚀 Features
- Smart appliance control
- Remote monitoring
- Sensor integration
- Automation system
- User-friendly interface

## 🛠 Technologies Used
- Python
- Raspberry Pi
- IoT
- Sensors
- OpenCV

## ▶️ How to Run
1. Clone the repository
2. Install required libraries
3. Run the main Python file
